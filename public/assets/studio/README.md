# Рендеры для Студии дизайна

Сюда кладутся реалистичные фигуры спортсмена на белом фоне (как в утверждённом макете).

## Структура

```
public/assets/studio/
  hockey/     front.png  back.png  [front-mask.png  back-mask.png]
  football/   front.png  back.png  ...
  volleyball/ ...
  basketball/ ...
  mma/        ...
```

## Требования к файлам

- **front.png / back.png** — фигура в полный рост, белый (#FFFFFF) или прозрачный фон,
  рекомендуемый размер 1200×1600 (3:4), формат PNG или WebP.
- **front-mask.png / back-mask.png** (опционально, включает перекраску джерси прямо на фото) —
  чёрно-белая маска той же геометрии: **белое = зона, которая перекрашивается** выбранным цветом,
  чёрное = не трогаем (кожа, шлем, фон). Маску легко получить из рендера в любом редакторе
  (или автоматически: `sharp`/`rembg` + выделение по цвету).

## Как включить

1. Положите файлы по путям выше.
2. В `lib/studioAssets.ts` поставьте `available: true` для нужного спорта.
3. Позиции фамилии/номера на спине настраиваются там же (`nameBox` / `numberBox`, в % кадра).

Без файлов Студия автоматически показывает векторную схему (фолбэк) — проект остаётся рабочим.

## Где взять рендеры

Сгенерированы через Canva (см. ссылки в переписке/отчёте): скачайте выбранный вариант как PNG
(Share → Download → PNG) и переименуйте в `front.png` / `back.png`.
