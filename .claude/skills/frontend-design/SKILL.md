# SANGER — дизайн-система и арт-дирекшн

Работай как арт-директор мирового агентства. Не упрощай. После каждого экрана
критикуй композицию, UX, типографику, мобайл и конверсию; если ниже 90% уровня
Nike — переделывай.

## Позиционирование (не забывать)
- SANGER — **цифровая фабрика командной экипировки на заказ**, не бренд одежды.
- Клиент хочет видеть на груди **свой** логотип, не SANGER. Логотип SANGER — только
  в шапке, футере, на упаковке/бирках, иногда на рукаве.
- Идея: «здесь сделают форму именно для нашей команды». Ощущение, что компания уже
  работает с сотнями клубов (разные названия, разные цвета формы).

## Стиль
Светлый, очень дорогой, очень чистый, современный минимализм, много воздуха,
большие фотографии реальных спортсменов, никакой мультяшности и дешёвых эффектов.

## Цвет (`tailwind.config.ts`)
- `paper #FFFFFF`, `ink #111111`, бренд `red #E4141C` (hover `red-600 #C90F16`).
- Серые строго нейтральные: `ink2`, `muted`, `line`/`line2` (волосяные границы).
- **Никаких цветных градиентов.** Допустим только нейтральный «живой свет»
  (radial низкой прозрачности) и красный акцент.
- Per-sport «атмосфера» — в `lib/atmosphere.ts` (свет, температура, частицы, клуб).

## Типографика
- Display — Montserrat 900 (`font-display`), body — Manrope (`font-sans`).
- Заголовки: огромные, смелые, UPPERCASE, `leading-[0.92]`, `tracking-[-0.02em]`,
  fluid `clamp(...)`. Минимум текста, крупные интервалы (уровень Apple).
- Красным красим 1 ключевое слово, не больше.

## Движение (`framer-motion` + `gsap` + `lenis`)
- Плавный инерционный скролл — `components/motion/SmoothScroll.tsx` (Lenis).
- Easing по умолчанию `[0.16, 1, 0.3, 1]`.
- Приёмы hero: масочный релиз строк, «дыхание» фигуры, параллакс по скроллу,
  тилт по указателю, красная строчка, микрочастицы.
- **Всегда** уважать `useReducedMotion()` / `prefers-reduced-motion`.
- Никаких дешёвых CSS-переходов ради «вау» — только дорогие, плавные.

## Фото
Только реалистичные спортсмены, на форме — логотип клиента. До появления реальных
фото использовать `AtmosphereHero` с плейсхолдером-джерси (проп `imageSrc` включает
`next/image` без изменения вёрстки). Файлы — в `public/assets/`.

## Структура посадочной (ТЗ)
Hero → Виды спорта → Преимущества → Производство → Материалы → Как проходит заказ →
Получить расчёт → Footer. **Без** «Наши работы» и **без** конструктора (он станет
отдельной страницей позже).

## Мобайл
Не уменьшенная копия — отдельный дизайн уровня приложения Apple. Каждый hero обязан
идеально смотреться на iPhone (проверять на 390×844).

## Компоненты-примитивы
`components/ui/*` (Button, Container, SectionHeading), `components/hero/AtmosphereHero.tsx`.
Переиспользовать, а не плодить варианты.

## HERO — эталон (правила уровня Nike/Apple/Awwwards)
Цель: за 3 секунды пользователь понимает «здесь сделают форму именно для МОЕЙ
команды». Каждый hero делается как отдельная сцена, не как «фото в карточке».

**Композиция (desktop):** слева — логотип + меню + kicker (напр. «СОЗДАЁМ
КОМАНДНЫЙ ДУХ»), огромный заголовок построчно (uppercase, `font-display`,
`leading-[0.92]`, `tracking-[-0.02em]`, `clamp(...)`), короткое описание, 2 CTA
(primary красный «Рассчитать стоимость» + ghost «Смотреть видео»), строка доверия
(собственное производство · с 2004 года · от 5 комплектов). Справа — **огромный
спортсмен, встроенный в сцену** (полноразмерная вырезка на прозрачном фоне, не в
рамке-карточке). На груди — логотип КЛИЕНТА (WOLVES/TITANS и т.п.), а SANGER —
только мелкими метками производителя (шлем/перчатки/гамаши).

**Фон hero:** белый ледяной, высокоключевой, воздух, лёгкий туман + микрочастицы.
Строим фон в CSS/DOM (radial white→ice, mist-блобы, частицы), а не тёмным фото.

**Красная нить = швейная нить** (не декоративная линия): начинается у текста,
проходит между слоями, один раз делает аккуратный узел, уходит ЗА спортсмена
(поэтому спортсмен — отдельный слой поверх нити) и заканчивается настоящей иглой.

**Появление (один раз при загрузке):** логотип → меню → заголовок построчно
(масочный релиз) → спортсмен въезжает справа → ледяная пыль под коньками → нить
прошивает экран → кнопки. Easing `[0.16,1,0.3,1]`, Lenis для скролла.

**Постоянные микро-анимации:** спортсмен едва дышит; ~раз в 10с блик по шлему;
нить чуть колышется; при движении мыши спортсмен / фон / нить двигаются с РАЗНОЙ
скоростью (деликатный параллакс). GSAP — для таймлайнов появления.

**Reduced-motion:** всё уважает `prefers-reduced-motion` — статичная, но красивая
композиция без движения.

**Мобайл hero — отдельная композиция** (не сжатый desktop): всё влезает в первый
экран (100svh), спортсмен остаётся главным объектом. Проверять на 375/390/393/430.

**Запрещено в hero:** карточки/рамки вокруг спортсмена, заглушки/плейсхолдеры,
SVG-«схематичный» спортсмен, стекломорфизм, градиенты ради градиентов, лишний
текст, читаемый вордмарк SANGER на груди.

**Проверка перед сдачей hero:** `npm run lint`, `npm run build`, Playwright на
desktop 1440/1920 и mobile 375/390/393/430; исправить найденное; показать скрины.
