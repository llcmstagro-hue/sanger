# Отчёт по анимации Higgsfield (image-to-video)

Модель: `seedance_2_0`, 720p, 16:9, 5 с, 22.5 кредита за клип.
Промпт: единый шаблон сохранения идентичности (лица/причёски/одежда/поза не менять,
не говорить, только дыхание/моргание/минимальное движение) + вариация движения камеры
по типу сцены: портрет — медленный dolly-in, прогулка — боковой слайд, объятия — почти
статичная камера, танец — лёгкий орбит на несколько градусов.

Тестовый клип (осенний парк) прошёл покадровую проверку идентичности:
кроп лиц первого/последнего кадра совпадает с исходником (профиль и причёска жениха,
заколка невесты без изменений). Остальные клипы сгенерированы тем же промптом.
